# v1.4.3 — Provider 历史估值与数据契约

发布日期：2026-10-04 · 类型：patch · 目标：Python 3.10+

## Added

- 百度股市通历史估值入口 `baidu_valuation_history`：按 A 股代码读取总市值、PE(TTM/静态)、
  PB、市现率图表，可选择近一年、三年、五年、十年或全部历史；值保留源端单位。
- 新入口接入 Baidu Provider 的 `catalog` channel 和统一 `Client.execute(QuerySpec)` 派发链，
  并提供 `WebQuoteSession` 直连方法。

## Improved

- 百度 K 线分页现在将请求根数限制在 1..10,000；检测到上游重复同一页/游标未前进时停止，
  避免无效翻页。非法请求在发出 HTTP 请求前拒绝。
- 文档明确各源指标的覆盖范围：腾讯是快照市值/PE/PB，新浪全市场摘要提供 PE/PB/总市值/流通市值；
  百度历史估值不含流通股数或股息率；东财 `valuation_history` 返回日频原始字段。

## Data limits

- 百度估值端点为非官方接口，响应结构和可用性可能变化；没有在本版本中猜测源端市值单位。
- 股息率不属于当前百度估值图表指标。历史股息率需要以明确的现金分红与价格/市值口径计算，
  应单独建模并标注除权日与计算假设；本版本不伪造该字段。
