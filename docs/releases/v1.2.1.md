# v1.2.1 发布说明

> tag：`v1.2.1` · 版本单一事实源：[`atst/_version.py`](../../atst/_version.py) = `1.2.1` ·
> 上一版本：[v1.2.0](v1.2.0.md)

## 一句话

本地安装实测（干净 venv 装 wheel，对全部 194 项能力逐一真实调用）暴露问题的收口发布：
修复 `interactive_qa` 源映射断链，10 项缺口能力的在线端点经真机验证后修正为真实报表名/端点，
`capability_statuses()` 相应由 `needs_verify` 转 `alive`。内核架构不变。

## 本地安装实测怎么做的

1. 干净 venv（Python 3.13.14）`pip install dist/atst-1.2.0-py3-none-any.whl`；
2. 枚举 `Client.capabilities()`（194 项），按四类后端解析每个能力的真实函数签名，
   自动生成最小参数，4 线程并发逐个 `Client.call(...)`；
3. 结果归类：出数据 / 成功 / 干净降级（`WebSourceError` / `CommandOffline`）/ 参数校验失败
   （缺必填参，预期行为）/ 真实缺陷。

实测口径与判据（探针脚本）不进仓库——本轮发现的缺陷已全部在源码修复并有针对性验证。

## Fixed

- **`interactive_qa` 断链（E8000）**：`cninfo` provider 的会话源映射为 `'cninfo'`，
  不在 `SOURCE_ALIASES` 之内，executor 构造 `WebQuoteSession` 即抛
  `CompatibilityError`。改按 `baidu`/`iwencai`/`builtin` 同款惯例映射名义源 `'sina'`。
- **14 个缺口报表名 9501（报表配置不存在）**：v1.2.0 落地时按命名惯例猜的报表名，
  实测大部分不存在。对照 akshare 源码与实时抓取找到真实端点，10 项能力修正并实测出数：

  | 能力 | 真实端点（2026-10-02 真机验证） |

  | `macro_lpr` | 东财 datacenter `RPTA_WEB_RATE`（1Y/5Y LPR，1576 行） |
  | `macro_bond_yield` | 东财 `RPTA_WEB_TREASURYYIELD`（中/美国债收益率多期限） |
  | `macro_social_financing` | 商务部数据中心 `shrzgmQuery`（社融增量月度） |

- `_em_clist_rows` 补 `rate_limiter.acquire`（此前绕过源层限流纪律）。

## 状态面变化

`Client.capability_statuses()` 中缺口能力：**10 项 `needs_verify` → `alive`**；
剩余 7 项保持诚实 `needs_verify`（`interactive_qa` / `news_broadcast` 端点主机在
沙箱不可达；`sw_industry` / `sw_industry_history` / `index_valuation` /
`futures_position_rank` / `options_position_rank` 无公开对应报表——期货/期权持仓排名
走 futsseapi 面板，需独立适配器，后续版本跟进）。4 个 tdx 死名字保持 `offline`。

## Verification

- 全量 194 能力逐个真实调用：126 直接可用或干净降级，其余为缺必填参数的校验性
  失败（预期行为）或探针假阳性；18 项缺口能力中 11 项真机出数（含离线 `trade_calendar`）。
- `ruff check` / `ruff format --check` / `mypy` 全绿；
  架构 + web + providers + compatibility 套件全绿。
- canonical 构建 `python scripts/build_package.py --smoke` 走通
  （PEP 517 隔离 → 产物形状校验 → `twine check` → 干净 venv 装 wheel 冒烟通过）。

## 已知边界

- 剩余 7 项 `needs_verify` 能力：端点失效时基座统一抛
  `SourceDeprecated` / `WebSourceError`（干净失败，不崩溃、不静默返回空）。
- 东财 push2 系对密集扫描有 IP 级软限流（本轮实测触发：连续数百次请求后
  `Server disconnected`）；生产使用请遵循源层 rate limiter 的节流节奏。
- 真实 Web 数据源可用性取决于服务端状态；联网能力不作为离线门禁。
