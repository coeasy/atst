# v2.0.0 发布说明

> tag：`v2.0.0` · 版本单一事实源：[`atst/_version.py`](../../atst/_version.py) = `2.0.0` ·
> 上一版本：[v1.6.1](v1.6.1.md) · 本次发布：[`v2.0.0`](https://github.com/coeasy/atst/releases/tag/v2.0.0) · 目标：Python 3.10+
>
> **发布后从 PyPI 安装**：`pip install atst==2.0.0`（上传由 `PUBLIC_RELEASE=true` 显式开关控制）；
> 亦可从源码或 Release 产物安装。定为 MAJOR：内部包布局与声明方式重排，迁移见
> [v1→v2 迁移指南](../migration/v2.md)；对外查询契约（路由 / 字段保留规则 / K 线时间语义 /
> symbol 归一化）保持不变。

## 一句话

v2 把「每 Provider 一个声明模块 + 唯一执行内核」落成默认结构：`catalog/` 取消、`web/` →
`sources/`、`integration/` → `server/`、`trade` 移入 `labs/`（wheel 排除）；对外仍是同一套
`Client` / `QuerySpec` / `QueryResult` 形状，217 项 capability 与精确绑定表不变。

## Changed

- **Provider 注册表声明化**：`atst/providers/` 由 14 个 Provider 声明模块 + 一个聚合器组成；
  废除反射式发现与三张覆盖表，`ProviderSpec` / `CapabilityBinding` 移入
  `providers/contract.py` 与 `providers/registry.py`。
- **包布局重排**：`atst/web/` → `atst/sources/`，`atst/integration/` → `atst/server/`；
  sources 内部按领域拆分（`_session_*`、`gaps`、`market`、`corporate`）。
- **执行内核拆分**：`runtime/executor.py` 拆为 `bindings` / `execute_*` / `composed`；
  `DIRECT_BINDINGS` 为 304 条精确绑定。
- **Client 动态面收敛**：废除 `Client.__getattr__` 任意转发，统一走 `call` 与显式方法；
  四服务面（CLI / HTTP / WS / MCP）同步改翻译层。
- **trade 移出主包**：`atst/trade/` → `labs/trade/`（wheel 排除），`PROTOCOL_SPEC/TRADE` 随迁。
- **文档生成制**：`scripts/gen_docs.py` 从注册表与运行期事实生成 `docs/generated/` 四张表。

## Added

- **零配置快捷入口**：顶层 `atst.history` / `atst.quote` / `atst.quotes` / `atst.minute` /
  `atst.trades`，默认 `provider="auto"`，返回 `list[dict]` / `dict`，内部仍走 `Client`。
- **能力检索**：`atst.search_capabilities` / `atst.describe_capability`，以及
  `atst capabilities --search/--describe/--status/--provider`（发现面仍保持纯名字形状）。
- `atst --version` 与 `atst version` 等价输出版本号。
- 交易日历在线校准（`trading_calendar`）、`quotes_batch` 并行批处理、六份 Provider 文档补齐。

## Fixed

- **新浪全市场计数不再静默截断**：`max_pages` 不足时按上游总数给出确定缺条数；节点空 /
  计数不可用分别发 `web_sina_node_empty` / `web_sina_count_unavailable` /
  `web_sina_market_count_mismatch`。
- **`quotes` 空结果统一告警**：请求非空但一行未取回时发 `quotes_empty_result`，与
  `quotes_partial_failure` 区分；`strict=True` 可拒收。
- **`direct_adapter` 导入路径随 `catalog/` → `providers/` 重排同步修正**，11 条 `direct_adapter` 绑定离线解析全部通过。

## Performance

- K 线解码：8 万条 0.689s → 0.413s（-40%）。
- 报价归一化：1000 只 0.391s → 0.324s（-17%）。
- 查询编译：单次 53.7 → 44.8 µs（-16%）。

## 升级

按 [v1→v2 迁移指南](../migration/v2.md) 调整导入路径；`atst --version` 与 `atst version`
均可确认版本。PyPI 上此前最新为 `1.6.1`，升级到 `2.0.0` 后新增的零配置入口才可用。
