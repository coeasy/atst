# atst v1.2.0

发布日期：2026-10-02（tag `v1.2.0`）

状态：**GitHub Release 已发布**（canonical wheel + sdist，附 `SHA256SUMS.txt` 与
`RELEASE-METADATA.json`）；**本包不在 PyPI 上**——PyPI 上传是显式 opt-in
（仓库变量 `PUBLIC_RELEASE=true`），尚未执行。GitHub Release 与 PyPI/Docker 发布是两条独立动作，
本版只走通了前者。

## 这一版收口什么

v1.2.0 对标 5 个开源行情项目（`1nchaos/adata`、`zhangxiangliang/stock-api`、
`simonlin1212/a-stock-data`、`ArvinLovegood/go-stock`、`clawyi-com/china-market-data`）的行情接口，
把盘点出的 13 项真实缺口（G-01~G-13，见
`docs/archive/plans/atst_覆盖与补全方案_对比5项目.md`）补齐为 18 个新能力，并新增一张
**能力健康度面**。内核架构（单执行路径 / 零缓存 / provider-first / 禁止隐式跨源 fallback）不变，
规模数推进到 **14 Provider / 194 capability / 280 条精确绑定**。

### Added — 18 项缺口能力

对标补全，四张服务面（Python / CLI / HTTP / WS / MCP）经通用分派自动贯通，无漏暴露断链：

- **交易日历**：`trade_calendar`（内置表，离线可用；2026 为估算值，与 `domain/calendar` 同口径）。
- **风险与资格**：`st_list`（ST/*ST 名单）、`equity_pledge`（股权质押）、`risk_scan`（个股风险扫描）。
- **估值**：`valuation_history`（个股 PE/PB/PS 日频序列）、`index_valuation`（指数 PE/PB/股息率）。
- **行业**：`sw_industry`（申万行业分类）、`sw_industry_history`（行业变迁史，避免前视偏差）。
- **资金与衍生品**：`etf_shares`（ETF 场内外份额）、`futures_position_rank` / `options_position_rank`
  （期货/期权会员持仓排名）。
- **宏观补全**：`macro_social_financing`（社融）、`macro_pmi`、`macro_lpr`、
  `macro_bond_yield`（中债曲线）、`macro_repo_rate`（回购定盘）。
- **另类**：`interactive_qa`（互动易 / e 互动问答）、`news_broadcast`（央视《新闻联播》文字稿）。

### Added — 能力健康度面

`Client.capability_statuses()`（`AsyncClient` 同名静态方法）返回 `{capability: status}`，
取值 `alive` / `degraded` / `offline` / `needs_verify`。单一事实源在
`atst.catalog.capability`：

- **显式叠加**：tdx 命令账本判定的 4 个死名字（`auction` / `block_quotes` / `minute_history` /
  `volume_price`）标 `offline`；缺口补全能力标 `needs_verify`（端点待真机抓包校准）。
- **注册表派生**：`ChannelSpec.unavailable_capabilities` 里「一个能力只有其每个归属 channel
  都下线」才判 `offline`（`minute` 只在 tdx 下线、别处仍在线，故不算；`security_list_all`
  只归属 tdx，故判死）。

**发现面保持只有名字**（`Client.capabilities()` / `GET /v13/capabilities` / WS
`runtime.capabilities`）——这是 F-66(c) 的冻结形状，条目类型清一色 `str`，状态走独立方法。
「名字 ≠ 可用性」这条口径因此有了机器可读版本。

### Changed

- 规模数：**189 个 catalog 迁移能力 / 194 项总能力**（原 171 / 176），`DIRECT_BINDINGS`
  262 → 280。`docs/ARCHITECTURE.md` / `README.md` / `docs/api/README.md` /
  `docs/api/interfaces.md` / `docs/quickstart.md` 的钉死数字同步对齐。
- `Client` 公开方法数 16 → 17（新增 `capability_statuses`；`interfaces.md` 的方法表同步补行）。

### Fixed

- **互动易 `_parse_qa` 断链**：`CninfoSource._parse_qa` 引用了未定义的 `_s` 帮助函数与未导入的
  `Mapping`（运行时 `NameError`），补齐后正常。
- **新闻联播端点导入**：`atst.web.news.CctvNewsSource` 缺少 `WebSourceError` 导入，补齐。
- **孤儿 API 清理**：移除未被任何调用点引用的 `available_capabilities()`；
  `capability_status()` 收口为状态查询唯一入口，`capability_statuses()` 经它构造。

## 兼容性

- Python：`>=3.10`，支持 CPython 3.10、3.11、3.12、3.13、3.14（3.13/3.14 的 argparse `%` 与
  `asyncio.start_server` 同步回调两类解释器陷阱由门禁守住，见
  `tests/compatibility/test_interpreter_hazards.py`）。
- 核心安装零硬依赖；DataFrame / Parquet / DuckDB / Web / Metrics / Server / MCP 按 extras 安装。
- 同步 `TdxClient` 与异步 `AsyncTdxClient` API 保持镜像语义。
- 新增能力均为「数据型 / 派生型源」，不参与行情降级链；返回形状见
  `docs/api/interfaces.md`。
- 发现面形状**未变**（仍是纯 `str` 名单），因此不构成破坏性变更；状态新增在独立方法上。

## 安装

> **实测口径**：`https://pypi.org/pypi/atst/json` 与 `https://pypi.org/simple/atst/` 均回 404——
> PyPI 上没有 `atst` 这个名字，`pip install atst` 今天装不通。可执行的路径是下面两条。

从源码安装（当前稳定线）：

```bash
git clone https://github.com/coeasy/atst.git && cd atst
pip install ".[all]"
```

或安装构建产物（由发布流水线产出）：

```bash
# 本地复刻产物形态：
python scripts/build_package.py            # 产出 dist/atst-1.2.0-py3-none-any.whl 与 sdist
pip install dist/atst-1.2.0-py3-none-any.whl
```

## 已知边界

- 除 `trade_calendar`（内置、离线可用）外，其余 17 项缺口能力的在线端点为 **best-effort**：
  报表名/端点待真机抓包校准，故在 `capability_statuses()` 中标 `needs_verify`。端点失效时基座
  统一抛 `SourceDeprecated` / `WebSourceError`（干净失败，不崩溃、不静默返回空）。
- 真实 Web 数据源可用性取决于服务端状态；联网能力不作为离线门禁。
