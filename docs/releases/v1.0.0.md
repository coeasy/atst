# tstdx v1.0.0

发布日期：2026-09-09

状态：正式稳定版（Stable）

## 发布摘要

v1.0.0 是 tstdx 的首个正式稳定发布版本，支持 Python 3.10–3.13。该版本重点收口
主站连接池的生命周期与并发状态治理，并补齐 F10 文件下载的真实响应解析契约。

## 主要变更

- `ConnectionPool` 与 `AsyncConnectionPool` 引入 generation/lease 生命周期保护；
  主站热更新、连接复用、空闲回收和在飞请求互不破坏。
- 后台测速排序与 real-request health 分离维护，测速结果不会覆盖线上健康状态。
- half-open circuit 在同步/异步路径均采用单探测门禁，避免并发探测风暴。
- 心跳、失败/成功回写、`update_hosts` 和旧 generation 完成回写均增加并发保护。
- F10 0x06B9 文件分块下载改用规范文件响应解析器，空响应明确抛出 `DataError`。
- 新增连接池生命周期、并发 half-open、健康排序隔离和代际回写保护回归测试。

## 兼容性

- Python：`>=3.10`，支持 CPython 3.10、3.11、3.12、3.13。
- 核心安装零硬依赖；完整能力可安装 `tstdx[all]`，开发环境可安装 `tstdx[dev]`。
- 同步 `TdxClient` 与异步 `AsyncTdxClient` API 保持镜像语义。
- `tstdx.native` 已进入弃用窗口：v1.5.0 发出强告警，v1.6.0 按时间线删除；迁移请使用
  `tstdx.codec` / `tstdx.io` 中的 Python 实现。

## 安装与升级

```bash
pip install --upgrade tstdx==1.0.0
```

从源码安装：

```bash
pip install "tstdx[all]==1.0.0"
```

## 发布验证

发布前已完成：

- `python -m pytest -q` 全量测试；
- `ruff check tstdx tests`；
- `python -m compileall -q tstdx tests`；
- `python scripts/build_package.py --smoke` 构建、临时虚拟环境安装和 import 冒烟。

发布产物：

- `tstdx-1.0.0-py3-none-any.whl`
- `tstdx-1.0.0.tar.gz`

GitHub Release 发布后，release workflow 使用同一 canonical distribution artifact，
在安装矩阵通过并完成 PyPI Trusted Publishing 后，将上述 wheel/sdist 附加到对应
GitHub Release 的资产栏；Docker 发布也继续复用同一个已经验证的 wheel，不二次构建。

## 已知边界

真实主站、Web 数据源和 F10 内容是否可用取决于服务端状态；联网能力不作为离线测试
门禁。协议中仍标记为待真机定标的命令，继续遵循对应的 L2/L3 降级与错误语义。
