# atst v1.0.0

发布日期：2026-09-28（历史方案日期 2026-09-09 / 2026-09-27 仅保留在变更记录中）

状态：**已发布**——GitHub Release [`v1.0.0`](https://github.com/coeasy/atst/releases/tag/v1.0.0)
由推送 `v1.0.0` 标签触发的 `.github/workflows/wheels.yml` 构建 canonical wheel + sdist，并附
`SHA256SUMS.txt` 与 `RELEASE-METADATA.json`。**PyPI 尚未发布**：上传是显式 opt-in，需仓库变量
`PUBLIC_RELEASE=true` 才经 OIDC trusted publishing 推送。

## 发布摘要

v1.0.0 是 `atst` 名称下计划发布的首个稳定版本：本库更名为 `atst`，包名 / 导入名 / 控制台入口 / wheel 与
sdist 产物统一为 `atst`。它将作为 `atst` 这一名字下的首次公开发行，破坏性变更（环境变量前缀
`TSTDX_` → `ATST_`、指标名前缀 `tstdx_` → `atst_`）见 [CHANGELOG](../../CHANGELOG.md)
的 2026-09-27 条目。

v1.0.0 是 `atst` 的首个稳定版本，支持 Python 3.10–3.14。该版本重点收口
主站连接池的生命周期与并发状态治理，并补齐 F10 文件下载的真实响应解析契约。

## 主要变更

- `ConnectionPool` 与 `AsyncConnectionPool` 引入 generation/lease 生命周期保护；
  主站热更新、连接复用、空闲回收和在飞请求互不破坏。
- 后台测速排序与 real-request health 分离维护，测速结果不会覆盖线上健康状态。
- half-open circuit 在同步/异步路径均采用单探测门禁，避免并发探测风暴。
- 心跳、失败/成功回写、`update_hosts` 和旧 generation 完成回写均增加并发保护。
- F10 0x06B9 文件分块下载改用规范文件响应解析器，空响应明确抛出 `DataError`。
- 新增连接池生命周期、并发 half-open、健康排序隔离和代际回写保护回归测试。

## 兼容性

- Python：`>=3.10`，支持 CPython 3.10、3.11、3.12、3.13、3.14。
- 核心安装零硬依赖；完整能力可安装 `atst[all]`，开发环境可安装 `atst[dev]`。
- 同步 `TdxClient` 与异步 `AsyncTdxClient` API 保持镜像语义。
- `atst.native` 已进入弃用窗口：v1.5.0 发出强告警，v1.6.0 按时间线删除；迁移请使用
  `atst.codec` / `atst.io` 中的 Python 实现。

## 安装与升级

> **安装路径的实测口径（2026-09-22 追加，G9）**：下面两条 `pip install` 今天装不通
> ——本包不在 PyPI 上（`https://pypi.org/pypi/atst/json` 与 `/simple/atst/` 均回
> 404）。可执行的路径是 clone 本仓库后 `pip install ".[all]"`，或安装构建产物
> `dist/atst-<版本>-py3-none-any.whl`。本节保留原文是为了记录当时的发布意图，
> 上架之后由真正完成发布的版本说明接管。

```bash
pip install --upgrade atst==1.0.0
```

从源码安装：

```bash
pip install "atst[all]==1.0.0"
```
