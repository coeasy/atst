## 一句话

v2.2.0 把重构方案（`docs/REFACTOR_PLAN.md`）的待办**全量落地**，并用 2026-11-23/24/25
三轮真机实测收口：内核按族常驻连接池、批量三态语义校正、流式生命周期 fail-closed、
量纲系数单源化、WS 订阅合流；真机暴露的非沪深缺省报价路由、港美股量纲缩放两个真 bug
当场修复并钉上回归。

## 为什么重要（实测依据）

真机实测不是走过场：`hk00700` / `usAAPL` 的缺省 `quotes()` 此前落到非 live 的
`catalog` 通道直接 E1010，腾讯 canonical 解析又把港美股套上 A 股量纲（成交额 ×10⁴、
成交量 ×100），隐含均价落在当日高低区间之外——两个问题在真机数据面前无处遁形，
修复后 `hk00700` 341.6 HKD / 量 29,393,105 / 额 10,123,426,303.24，隐含均价回到区间内。
官方 `TdxW.exe` 客户端的 9,507 个 `.day` 文件还证伪了"日线末字段 = 前收盘"的旧假设
（与上一根收盘匹配率 0/1284），复权链路不再吃进错误权威值。

## Added

- **本地板块/行业配置只读 reader**：`atst.reader.BoardConfigReader` / `IndustryConfigReader`
  解析官方客户端 `tdxbk.cfg`（58 条板块名表）/ `tdxhy.cfg`（5670 条股票→行业映射）；
  只做解析，不新增 Provider / capability，不做 GUI 抓取，不含成分股或行情。
- **Provenance.upstream**（P1-4）：聚合 Provider 结果披露真实出数源。
- **`atst serve --ws`**（P2-3）：WS 服务面补 CLI 入口，可与 HTTP 面同进程复用同一 Client。
- **逐文件覆盖率地板闸**（P3）+ 唯一生成器 `scripts/gen_coverage_floors.py`（238 键）。
- **`heartbeat_cmd` 配置键**、环境变量 bool 兼容（P3）。
- **TDX 板块指数报价**：`880xxx` / `881xxx` 归沪市命名空间（真机 `sh880001` 有完整报价）。
- **`quotes_snapshot(try_offline_snapshot=)`**：公开 opt-in，默认跳过已下线的 0x054C。
- **`atst/sources/_scale.py`**（P1-8）：价格 / 成交量 / 成交额换算系数唯一事实源，
  `tests/sources/test_scale_single_source.py` 三重守卫，新增源无法自造系数。
- **WS 订阅合流**（F-8）：等价订阅共享一条上游轮询，引用计数归零才停流，逐连接 fan-out。

## Changed

- **常驻连接池**（P1-1）：内核按族持有常驻家族客户端，批量不再每跳现造池 + 心跳线程。
- **北交所 bars 缺省路由**（P0-4）：BJ 与港美股同待遇转 Web 源；tdx 直连 BJ 归位为
  不可重试的 `ValidationError`（E1010）。
- **流式 stop 超时 fail-closed**（P0-7）、**WS 推送真丢帧**（P0-5/P0-6）、
  **协议 sniffer 默认关闭**（P0-8）。
- **启动审计闭环**（P0-9）：`audit_runtime()` 纳入绑定表自查与执行器方法存在性校验。
- **探测合一**（P1-7）：字符集/profile 两套探测抽公共打分内核（`atst/profile/scoring.py`）。
- **CLI 拆分**（P2-3）与**会话面瘦身**（P2-4）：约 1300 行按域拆四模块，19 个 Mixin 聚 4 域类。
- **P-4/P-6 协议收口**：命令账本成为 tier 唯一权威（49 行历史 `D` 更正为 `L2`）；
  握手三帧改由 `FrameSpec` 生成，真机线路形状不再靠手抄常量维持。
- **L2 启发式退化载荷降权**：全零 / 单字段载荷不再冒充 L2 表格（sniffer 语料 12 份中
  9 份误报被收口），回落 L3 原始透传。
- **复权文档口径**（2026-11-25 真机核对）：接口文档补齐 `Client.adjusted_bars` /
  `capital_changes` 一等公民方法与「自算复权 vs Web 服务端复权」对照；
  真机 hfq 因子 `7.39106838` 与 FAQ 一致。

## Fixed

- **非沪深缺省报价路由**（2026-11-24 真机）：港股 / 美股 / 北交所缺省 `quotes()` 不再
  E1010，按 symbol market 选 live Web 源（腾讯优先）；显式 `provider=` 不被重路由。
- **腾讯港美股 canonical 报价量纲**：`_parse_external_quote()` 统一外部市场布局，
  A 股缩放路径不变。
- **vipdoc 日线末字段误当 prev_close**（官方客户端真机）：仅接受与当日收盘同量级的值，
  其余置 `None`，复权走既有上一根收盘回退。
- **quotes_batch 坏符号语义**（P0-11）：状态由 `failed` 校正为 `not_attempted`。
- **调用方参数错污染 provider 健康**（P0-10 余项）。
- **集思录顶层非对象 JSON**：显式 `Mapping` 守卫，保住 E7030「源已改版 / 需 cookie」信号。
- **docker-compose 启动失败**：删除未注册环境键、修端口冲突 / 悬空卷。
- **README 绑定数漂移**：四处 304 更正为现算的 299，并加现算判据门禁。
- **`.day` 补洞时序**、**sink CSV 一致性**、**BinaryWriter 越界**、**配置单例竞态**（P3 族）。

## Deprecated

- `AsyncTdxClient` / `AsyncConnectionPool`：生产 async 只有 `AsyncClient`；
  物理移除排在 v2.3（breaking）。

## 升级

无需改代码。对外查询契约不变；`pip install -U atst` 即可。使用 legacy
`AsyncTdxClient` 的调用方建议迁移到 `AsyncClient`（v2.3 将物理移除）。
