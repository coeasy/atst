# atst 1.0.1 发布说明

**1.0.1 收口两件事：复权 K 线（`adjusted_bars`）从"纸面能力"变成真实可用，行情查询接口全面灵活化（日期区间 + strict/currentness 贯通五面），并消掉一批无界等待 / 无界循环 / 无界内存。**

## 本版核心

### 复权 K 线真正可用

- 原始 K 线缺省走 **Provider 在线取数**（默认 `tdx`；本地 vipdoc 有文件时优先读本地）——没有本地数据的调用方也能复权。
- 除权除息事件缺省取**东财 `dividend_history`**：`BONUS_RATIO` 送股 / `IT_RATIO` 转增 / `PRETAX_BONUS_RMB` 每 10 股派息，列名已与公告对拍（002594 送 8 / 转 12 / 派 39.74）。
- TDX `0x000F` 的结构化记录布局与真机记录不符（解码后日期 / 市场 / 代码全乱），`event_source="tdx"` 降级为**显式 opt-in** 且过 `reject_implausible_changes` 合理性闸。
- 复权因子的现金红利项所需**前收盘价**由复权序列前一根 bar 的收盘推导，跨除权日精确计入派息；孤立 bar 退化处理并记 `adjust_prev_close_missing` 告警。
- 五面调用形状（Python / CLI / HTTP / WS / MCP）见 [接口文档的复权节](../api/interfaces.md)。

### 行情接口灵活性

- `QuerySpec` / `Client.bars()` / HTTP / WS / MCP / CLI 全部支持 **`start_date` / `end_date` 日期区间**；区间起始端取不到更早数据时记 `bars_range_uncovered` 告警。
- **`strict` / `currentness` 贯通五面**：此前只有 Python 通道生效，其余面静默忽略。
- `bars(adjustment=…)` 显式拒绝：不允许静默复权，复权必须走 `adjusted_bars` 能力。

### 稳定性

- 限流 `acquire`、连接池获取点、异步清理等待全部加**超时上界**——卡死的上游不再拖死调用方。
- 交易日扫描、流式停止屏蔽、WS 推送背压（满 64 帧丢最旧）、诊断告警 sink 全部**有界化**。

### WS 控制面对齐（发布前全链路审查补）

- **`runtime.health` 补 `direct_bindings`**：与 HTTP `/v13/runtime/health` 同一读数，两面运维口径一致。
- **`list` 补 `symbols` / `provider`**：订阅表此前只回 `id` + `state`，客户端无法按标的对账或退订；现在每条订阅带标的列表与出处 Provider，退订与连接关闭时同步回收。

## 升级

从 1.0.0 升级：`adjusted_bars` 的调用形状不变；`bars` 新增可选的 `start_date` / `end_date`；依赖行为无破坏性变更。
