# 迁移指南：v1 → v2（REFACTOR_V2）

> 适用对象：直接 import `atst` 内部模块的调用方、依赖旧目录结构或个人脚本的维护者。
> **对外业务契约不变**：`Client` / `AsyncClient` 的 Tier-A 方法、`QuerySpec`、`QueryResult`、
> `Provenance`、错误码（E1010 / HTTP 422 / JSON-RPC -32602 / CLI 退出码 2）全部保持。
> 变的是**包结构、Provider 注册表形态、执行器内部拆分与文档生成方式**。

## 0. 一页速查

| v1 | v2 |
|---|---|
| `from atst.web import ...` | `from atst.sources import ...` |
| `from atst.web.eastmoney import ...` | `from atst.sources.eastmoney import ...` |
| `from atst.integration import ...` | `from atst.server import ...` |
| `from atst.catalog import ...` | 删除；用 `Client.call(<capability>, ...)` |
| `client.<dynamic_name>(...)`（`__getattr__`） | `client.call("<capability>", ...)` |
| `from atst.runtime.executor import _ADJUSTABLE_PERIODS` | `from atst.runtime.composed import _ADJUSTABLE_PERIODS` |
| `from atst.trade import ...` | `from labs.trade import ...`（**不在 wheel 内**） |
| `providers.PROVIDER_CAPABILITIES_OVERLAY` 等三张覆盖表 | 各 Provider 声明模块的 `BINDINGS` / `CAPABILITIES` |
| `atst.transport.pool.CIRCUIT_OPEN_AT` 等 | `atst.transport.policy.CIRCUIT_OPEN_AT`（`pool` 仍重导出） |
| `docs/api/interfaces.md` 手写规模数字 | `docs/generated/*`（`make docs-gen` 生成） |

## 1. 导入路径迁移

| 旧 import | 新 import |
|---|---|
| `atst.web` | `atst.sources` |
| `atst.web.tencent` / `.sina` / `.eastmoney` / `.baidu` / `.jsl` / `.boc` | `atst.sources.tencent` / `.sina` / `.eastmoney` / `.baidu` / `.jsl` / `.boc` |
| `atst.web.cninfo` / `.ths` / `.wallstreet` | `atst.sources.cninfo` / `.ths` / `.wallstreet` |
| `atst.integration` | `atst.server` |
| `atst.integration.http` | `atst.server.runtime_http` |
| `atst.integration.ws` | `atst.server.runtime_ws` |
| `atst.catalog` | 无对应模块：能力目录在 `atst.providers`，调用统一走 `Client.call` |

批量替换（在**你自己的**代码库里执行，仓库内已完成）：

```bash
# 1) 包重命名
grep -rl "atst\.web" --include="*.py" . | xargs sed -i 's/atst\.web/atst.sources/g'
grep -rl "atst\.integration" --include="*.py" . | xargs sed -i 's/atst\.integration/atst.server/g'

# 2) 动态 Client 方法 → call
#    先找出所有 `client.<非 Tier-A 方法>(` 调用，再逐个改成 `client.call("<capability>", ...)`
grep -rn "client\.\([a-z_]\+\)(" --include="*.py" .

# 3) trade 移到 labs（仅源码仓库可用；wheel 不打包 labs）
grep -rl "atst\.trade" --include="*.py" . | xargs sed -i 's/atst\.trade/labs.trade/g'
```

## 2. Provider 注册表

- 每个 Provider 一个声明模块：`atst/providers/<provider>.py`，同时登记
  `CHANNELS`（channel → adapter）与 `BINDINGS`（capability → 实现）与 `STATUS`。
- 聚合器 `atst/providers/__init__.py` 只做 `PROVIDERS` / `MIGRATED_BINDINGS` /
  `MIGRATED_CAPABILITIES` / `COMPOSED_CAPABILITIES` 投影；**不再有反射扫描与三张覆盖表**。
- 新增 Provider：加一个声明模块并在 `providers/__init__.py` 注册，不要改 `registry.py` 的词汇表。

```python
# 新版声明形状（示意）
SPEC = ProviderSpec(
    id="example",
    role="auxiliary",
    channels=(_c("catalog", "foo", "bar"),),
    bindings=(
        CapabilityBinding("foo", provider="example", channel="catalog",
                          backend="web_session", method="fetch_foo", source="example"),
    ),
)
```

## 3. Client 动态面

`Client.__getattr__` / `AsyncClient.__getattr__` 已删除：拼错能力名不会再"运行时才炸"。
迁移方式：

```python
# v1（隐式动态分派）
rows = client.hot_rank(provider="eastmoney")

# v2（显式能力名；HTTP/WS/MCP 三面同一入口）
rows = client.call("hot_rank", provider="eastmoney")
```

Tier-A 方法（`quotes` / `bars` / `history` / `minute_klines` / `flush` …）保持不变。
`Client.capabilities()` 仍是 `tuple[str, ...]`；新增 `trading_calendar`（在线交易日历）。

## 4. 执行器拆分

`atst/runtime/executor.py` 现在只保留 `DirectProviderExecutor` 壳：

| 旧位置 | 新位置 |
|---|---|
| `executor.DEDICATED_CAPABILITIES` / `DIRECT_BINDINGS` / `DirectBinding` | `atst.runtime.bindings`（`executor` 仍重导出） |
| `executor` 里的 channel/capability 执行体 | `atst.runtime.execute_channel` / `execute_capability` |
| `executor` 里的组合能力（复权/同步/富集） | `atst.runtime.execute_composed` + 常量在 `atst.runtime.composed` |
| `executor._ADJUSTABLE_PERIODS` / `_COARSE_DAYLIKE_PERIODS` | `atst.runtime.composed` |

## 5. transport 正规化

熔断与槽位选择搬到 `atst.transport.policy`；`pool.py` / `async_.py` 只做 IO。
旧常量仍可从 `atst.transport.pool` 导入（`__all__` 重导出），但新代码请直接 import policy。
`sys._getframe` 调用栈探测已删除：解码告警的 `stacklevel` 由显式 hop 深度计算。

## 6. sources 内部重排

| 旧模块 | 新模块 |
|---|---|
| `atst/sources/_session_p1.py` | `atst/sources/_session_esg_chip.py` |
| `atst/sources/_session_p2.py` | `atst/sources/_session_sector_macro.py` |
| `atst/sources/_session_p3.py` | `atst/sources/_session_holders.py` |
| `atst/sources/_session_gaps.py` | `atst/sources/_session_research.py` |
| `atst/sources/corporate.py`（单文件） | `_corporate_common.py` / `_corporate_financial.py` / `_corporate_market.py`（`corporate.py` 仍是 facade） |

> **patch 面变化**：`monkeypatch("atst.sources.corporate._shared_http")` 之类的旧目标
> 需要改到实际实现模块（例如 `atst.sources._corporate_financial`）。

## 7. trade → labs

`atst/trade/` 移到 `labs/trade/`：**不进 wheel**（`pyproject.toml` 的 `packages=["atst"]`），
sdist 仍包含 `labs`，方便源码仓库开发。import 改为 `from labs.trade import ...`。

## 8. 文档

- 投影型文档（Web 源登记、capability × provider 矩阵、四张服务面、命令账本）由
  `make docs-gen` 生成到 `docs/generated/`；守卫只判"生成物 == 重新生成的结果"。
- 交易日历：`trading_calendar`（Eastmoney 在线校准，`freshness` 标记，
  `set_holidays()` 手动覆盖优先）取代旧的"内置表 + 估算"单一路径；
  旧的 `trade_calendar`（builtin）仍保留为离线兜底。
