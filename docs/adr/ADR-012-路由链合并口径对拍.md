# ADR-012：facade 路由链 vs DataSourceRouter 五级链口径对拍

- 状态：已取代（Superseded by v16 单内核）—— 本文对拍的两个对象 `facade.UnifiedQuoteAPI` 与 `sources.DataSourceRouter` 均已物理删除，五级降级链不复存在；
  对拍结论中仍有效的**口径归一化**部分由 `atst.web.normalize` 与 capability 目录继承。
- 日期：2026-09-06
- 关联：REFACTOR_PLAN_v9.md Q1-a / ARCHITECTURE_AUDIT_v8.md §二.A.2 / ADR-011（复审节奏）

## 背景

`facade/api.py`（UnifiedQuoteAPI，local→tdx→web 三链，面向交互面）与
`sources.DataSourceRouter`（tdx→web→reader→cache→synthetic 五级链，面向数据面）
的取数内核高度同源（都最终调 `TdxClient` / `WebQuoteClient` / `DayBarReader`），
但存在多处口径差异，且从未逐项对拍。Q1-a 以**离线 mock 对拍测试**
（`tests/facade/test_route_parity.py`）把差异锁定，并实施已裁定的对齐。

## 差异清单与裁定

### D1 start 偏移语义 —— 已裁定：以 facade 为准（本次已实施）

facade `bars`（local/tdx）支持 `start` 偏移（`end=len-start, begin=end-count`）；
router 只支持「末尾 count 根」。**裁定以 facade 为准**：
`DataSourceRouter.kline` 与 `_reader_kline` 新增可选参数 `start: int = 0`，
tdx 分支透传给 `c.bars`（`TdxClient.bars` 本就支持 start）。
`start=0` 行为与历史版本完全一致（向后兼容）。

### D2 空结果语义 —— 已裁定：保留双口径，Q1-b 用 default_empty_ok=True 合并

facade `_try_routes` 视「不抛异常」为成功（含合法空列表）；router 默认
空 = 本源不可用继续降级。**裁定**：本次不改 router 默认（默认口径有
独立价值：区分「源故障」与「合法空」）；router 已有 `default_empty_ok`
开关，Q1-b 合并时 facade 单源调用将传 `default_empty_ok=True`。

测试锁定的**边缘情形**：`start >= len` 时窗口为空——facade local 返回
`[]`（成功），router 默认抛 `AllSourcesExhausted`；`default_empty_ok=True`
时两链一致返回 `[]`。该情形随 D2 一并收敛。

### D3 web adjust 口径 —— 已一致，锁定

facade web 传 `adjust=None → ""`（原始价），router web 固定 `adjust=""`。
两链 web klines 的 adjust 参数逐字相等（对拍测试断言），无需改动。

### D4 连接生命周期 —— 裁定：Q1-b 由 facade 熔断壳持有 router 实例解决

facade 的 tdx/web 客户端为**惰性创建、实例级持久**（`close()` 统一释放，
熔断状态跨调用保持）；router 每次 calls **新建客户端并即用即关**
（`with TdxClient(...)` / `client.close()`）。本次不改代码。**裁定**：
合并时 facade 作为壳持有 router 实例——持久性由壳的熔断与连接管理提供，
router 内部「即用即关」语义保持不变（其本就设计为可反复新建）。

### D5 输出形态 —— 裁定：行为兼容，保留

facade tdx 调 `as_format="obj"`（返回 Quote/Bar 模型，面向交互面）；
router 固定 `as_format="dict"`（数据面）。reader 通路两链返回行**逐字段
相等**（`DayBarReader.read(output="dict")` 即 `Bar.to_dict`，对拍测试
已断言）。这是接口契约差异而非数值口径差异，合并不改。

### D6 符号归一化位置 —— 测试中发现的新差异，裁定：行为兼容优先，Q1-b 收敛

- `facade` 所有入口先 `normalize_symbol` 再下发；
- `router.quotes` **透传原始串**给 client（不归一化）；
- `router.kline` 虽经 `split_symbol` 提取 code（cache 源用），tdx 分支仍
  **透传原始串**给 `c.bars`。

对 canonical 输入（`sh600519`）两链行为完全一致（测试即以 canonical
输入对拍）；非 canonical 输入依赖 `TdxClient` 内部归一化兜底，行为兼容。
**裁定**：本次不改（避免扩大面）；Q1-b 合并时归一化统一收在 facade 壳，
router 入口补 `normalize_symbol`。

### D7 构造参数差异 —— 测试中发现的新差异，裁定：兼容，不改

- facade 构造 `TdxClient(timeout=...)` / `WebQuoteClient(timeout=...)`，
  router 不传 timeout（client 默认值）；
- router web 源固定 `WebQuoteClient(sources=[KLINE])`，facade 用构造配置
  （默认含 KLINE）。

均不影响返回口径（默认源一致、默认超时一致），保留。

### D8 能力面差异 —— 裁定：保留（正是两链存在的理由）

facade local 仅 day（显式报错 week/month）；router reader 支持
day/1min/5min；router 独有 cache/synthetic 两级与 kline_cache/quote_cache
接线；facade 独有熔断与口径守卫（W11/W13）。合并不是抹平能力面，
而是壳（facade）+ 内核（router）分层。

## 实施（Q1-a 范围）

1. `atst/sources/__init__.py`：`DataSourceRouter.kline` 与 `_reader_kline`
   新增 `start: int = 0`（D1），tdx 分支透传；行为向后兼容。
2. 新增 `tests/facade/test_route_parity.py`（11 个用例）：
   tdx/web/reader 三通路 mock 对拍、D1 start 语义、D2 空结果、
   D3 adjust 锁定、start≥len 边缘钳制。
3. 连接生命周期（D4）仅记录，不改代码（Q1-b 处理）。

## 后果

- 两链 (symbol, period, count, start) 窗口口径与 web 复权口径从此有
  回归测试锚定；Q1-b 合并时以本对拍为验收基线。
- router 新参数默认 0，既有调用方零感知。

## 备选方案（未采纳）

- **router 默认改为「空=成功」**：会掩盖「源故障」与「合法空」的区别，
  降级链失去意义；以显式 `default_empty_ok` 开关表达更精确。
- **本次顺手给 router 入口补 normalize_symbol（D6）**：行为兼容但属
  Q1-b 合并范畴，单独改动会放大本次 diff、混淆对拍基线。
